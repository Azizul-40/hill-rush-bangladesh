# অ্যাকাউন্ট, ইমেইল কোড ও ক্লাউড সেভ — সেটআপ (v45)

গেমে ইমেইলে ৬ সংখ্যার কোড দিয়ে অ্যাকাউন্ট খোলা, লগইন, PIN ভুলে গেলে রিসেট, নাম বদল, অ্যাভাটার আর ক্লাউড সেভ যোগ হয়েছে।
এগুলো কাজ করতে তিনটা জিনিস একবার করে দিতে হবে (আমি তোমার Cloudflare বা ইমেইল অ্যাকাউন্টে ঢুকতে পারি না)।

## ১) D1-এ নতুন টেবিল (একবার)
Cloudflare → Storage & Databases → D1 → `hillrush` → Console → `db/v45_new_tables.sql` ফাইলের তিনটা লাইন পেস্ট করে Execute।
(এটা আগের টেবিল ছোঁয়ে না, নতুন তিনটা টেবিল বানায়: `email_codes`, `profile`, `cloudsave`। আবার চালালেও ক্ষতি নেই।)

## ২) ইমেইল পাঠানোর সেবা (Brevo — ডোমেইন লাগে না)
1. https://www.brevo.com এ ফ্রি অ্যাকাউন্ট খোলো (দিনে ৩০০ মেইল ফ্রি)।
2. Senders & IP → Senders → Add a sender: তোমার জিমেইল (যেমন azizulcse16@gmail.com) দাও, Brevo যে যাচাইয়ের মেইল পাঠায় তাতে ক্লিক করো।
3. SMTP & API → API Keys → Generate a new API key (নামে `hillrush`), কপি করো।

(Resend ব্যবহার করলে নিজের ডোমেইন যাচাই করতে হয়, নইলে শুধু নিজের ইমেইলেই পাঠানো যায়। তাই Brevo সহজ।)

## ৩) Cloudflare Pages-এ গোপন মান
Pages → `hill-rush-bangladesh` → Settings → Variables and Secrets → Production (আর Preview) → Add:
| নাম | মান | ধরন |
|---|---|---|
| `BREVO_API_KEY` | Brevo-র API key | Secret |
| `MAIL_FROM` | Brevo-তে যাচাই করা প্রেরকের ইমেইল | Text |

তারপর Deployments → শেষ ডিপ্লয়মেন্ট → Retry deployment।

**কখনো `DEV_ECHO_CODE` দিয়ো না** — ওটা শুধু আমার টেস্টের জন্য, দিলে কোড ইমেইল ছাড়াই ফাঁস হয়।

## কীভাবে কাজ করে
- রেজিস্টার: ইমেইল দাও → "কোড পাঠাও" → ইমেইলে আসা ৬ সংখ্যা বসাও → নাম আর PIN ঠিক করো। কোড ১০ মিনিট বৈধ, ৪৫ সেকেন্ডে একবার পাঠানো যায়, ৫ বার ভুল হলে কোড বাতিল।
- লগইন: ইমেইল (বা পুরনো অ্যাকাউন্টের নাম) + PIN। ৫ বার ভুল PIN হলে ১০ মিনিট বন্ধ।
- PIN ভুলে গেলে: লগইন → "PIN ভুলে গেছি" → কোড → নতুন PIN। অন্য সব ডিভাইস লগ-আউট হয়।
- নাম বদল ও ছবি: প্রোফাইল বক্সে। লগইনের ইমেইল বদলায় না, শুধু দেখানোর নাম আর ছবি।
- ক্লাউড সেভ: লগইনের সময় সার্ভারের সেভের সাথে এই ডিভাইসের সেভ মেলানো হয়, তারপর প্রতিবার সেভ বদলালে ৪ সেকেন্ড পরে সার্ভারে যায়।
  - বড় মান রাখা হয়: আনলক করা লেভেল, শেষ করা লেভেল, মালিকানা (গাড়ি/ম্যাপ), আপগ্রেড, সেরা সময় (কম)।
  - কয়েন: সবচেয়ে নতুন সেভের মান। তবে অন্য ডিভাইসে কেনা জিনিসের দাম তা থেকে কাটা যায়, নইলে একই কয়েন দিয়ে দুবার কেনা যেত।
- লিডারবোর্ডে এখন "মোট আয় 🪙" (খরচ করলে কমে না), আর নামের আগে অ্যাভাটার।

## সীমাবদ্ধতা (সৎভাবে)
- আসল ইমেইল পাঠানো আমি এখান থেকে পরীক্ষা করতে পারিনি (কী না থাকায়)। কোড তৈরি, যাচাই, রিসেট, সিঙ্ক সব নকল D1 দিয়ে পরীক্ষিত; Brevo API-র সাথে আসল সংযোগটা তুমি কী বসানোর পর প্রথম রেজিস্টারেই দেখা যাবে।
- ক্লায়েন্টে থাকা সেভ কেউ নিজে বদলে জাল করতে পারে; সার্ভার শুধু আকার ও ফরম্যাট দেখে।
- এক জায়গায় আলাদা আলাদা সময়ে খেললে কয়েনে সামান্য অমিল হতে পারে (নতুনটাই জেতে)।
