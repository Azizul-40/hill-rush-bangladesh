# লিডারবোর্ড চালু করার ধাপ (Cloudflare D1)

কোড (`functions/api/*`, `db/schema.sql`) রিপোতে আছে। কিন্তু ডাটাবেস তৈরি ও জোড়া লাগানো Cloudflare ড্যাশবোর্ডে হাতে করতে হয় (এটা এখান থেকে করা যায় না)। না করলে গেমে লিডারবোর্ড স্ক্রিন খোলে, কিন্তু "অনলাইন সার্ভার সংযুক্ত নয়" দেখায়; শুধু এই ডিভাইসের সেরা সময় থাকে।

1. dash.cloudflare.com → **Storage & Databases → D1 SQL database → Create** → নাম: `hillrush`।
2. ডাটাবেসের **Console** ট্যাবে `db/schema.sql`-এর পুরো লেখা পেস্ট করে **Execute**।
   - v39-এ টেবিল বদলেছে (`players`-এ নাম/PIN কলাম, নতুন `tokens` আর `endless` টেবিল)। আগে v17-এর schema চালিয়ে থাকলে পুরোনো টেবিলগুলো মুছে (`DROP TABLE scores; DROP TABLE players;`) নতুন schema আবার চালাও। ডেমোর ডেটা হারাবে, এখনো কেউ ব্যবহার করেনি বলে সমস্যা নেই।
3. **Workers & Pages → hill-rush-bangladesh → Settings → Bindings → Add → D1 database**:
   - Variable name: `DB` (ঠিক এই নামেই)
   - D1 database: `hillrush`
   - Production ও Preview, দুটোতেই।
4. **Deployments → Retry deployment** (বা নতুন কমিট পুশ)। বাইন্ডিং নতুন ডিপ্লয়ে কাজ করে।
5. গেম খুলে **LEADERBOARD → গেস্ট হিসেবে খেলো** চাপো, একটা লেভেল (৮ সেকেন্ডের বেশি সময় নিয়ে) শেষ করো। তালিকায় নাম আসলে চালু।

## কীভাবে কাজ করে (v39)
- **গেস্ট:** নাম-PIN ছাড়া, "Guest-1234" নামে। শুধু ওই ডিভাইসে থাকে।
- **রেজিস্টার:** অনন্য নাম + ৪–৮ সংখ্যার PIN (ইমেইল ঐচ্ছিক)। PIN সার্ভারে লবণ-মেশানো SHA-256 হ্যাশ হিসেবে থাকে, আসল PIN নয়।
- **লগইন:** অন্য ফোনে নাম + PIN দিলে একই প্রোফাইল। প্রতিটি লগইনে নতুন টোকেন। ৫ বার ভুল PIN দিলে ১০ মিনিট লগইন বন্ধ।
- **গেস্ট → নিবন্ধিত:** একই প্রোফাইল থাকে, আগের স্কোর হারায় না।
- **তালিকা:** সামগ্রিক (শেষ করা লেভেল, মোট সময়), প্রতি লেভেলে সেরা সময়, প্রতি ম্যাপে এন্ডলেস দূরত্ব। লেভেল/এন্ডলেস শেষে নিজের র‍্যাংক দেখায়। লগইনের পর এই ডিভাইসের আগের রেকর্ড নিজে থেকে জমা হয়।
- **রেকর্ড পাতা:** মোট দূরত্ব, স্টান্ট, আনলক করা গাড়ি/ম্যাপ, অনলাইন সামগ্রিক র‍্যাংক।

## সীমাবদ্ধতা (সৎভাবে)
- PIN ভুলে গেলে ফেরানোর উপায় নেই (ইমেইল দিয়ে রিকভারির জন্য ইমেইল-সেবা লাগবে, যোগ করা হয়নি)। ইমেইল যাচাইও হয় না।
- ৪–৮ সংখ্যার PIN দুর্বল পাসওয়ার্ড; লক-আউট থাকলেও এটা ডেমো-মানের নিরাপত্তা, ব্যাংকের মতো নয়।
- স্কোর ক্লায়েন্ট থেকে আসে, তাই জাল স্কোর পুরোপুরি আটকানো যায় না; শুধু সীমা-পরীক্ষা (সময় ≥ ৮ সেকেন্ড, মান-সীমা) আছে।
- সংরক্ষিত ইমেইল ব্যক্তিগত তথ্য। প্রকাশ্য করার আগে গোপনীয়তার নীতি/সম্মতি ভাবতে হবে (বিশ্ববিদ্যালয় প্রজেক্টে ডেমোর জন্য ঠিক আছে)।
- কোড এখনো আসল Cloudflare D1-এ চালানো হয়নি; পরীক্ষা হয়েছে `node:sqlite`-ভিত্তিক নকল D1-এ (`tests/leaderboard_api_test.js`, `tests/v17_leaderboard_ui_test.js`)।
