# প্রজেক্ট ভিশন — HILL RUSH BANGLADESH

**Developed by Azizul & Habiba · Supervised by Md. Hasibur Rahman**

## গেমটা কী
ব্রাউজারে চলা একটা মনস্টার-ট্রাক হিল-ক্লাইম্ব গেম (HTML + CSS + JavaScript + Canvas)। প্লেয়ার পাহাড়ি রাস্তায় ট্রাক চালিয়ে কয়েন কুড়ায়, লেভেল শেষ করে, কয়েন দিয়ে ট্রাক আপগ্রেড করে ও নতুন ট্রাক/ম্যাপ কেনে।

## আমাদের লক্ষ্য
- বাংলাদেশের পাহাড়ি রাস্তার আবহ নিয়ে নিজেদের ডিজাইনের একটা গেম বানানো (নাম, ব্যানার, UI আমাদের নিজেদের)।
- প্রতিটা ফিচার আমরা নিজেরা বুঝে, পরীক্ষা করে যোগ করব এবং ব্যাখ্যা করতে পারব।
- ২D সংস্করণটাই এই প্রজেক্টের ফাইনাল ভার্সন। ভবিষ্যতে 3D (Three.js) করলে সেটা আলাদা ধাপ; গেম-লজিক আর ছবি আঁকা আলাদা রাখার চেষ্টা থাকবে।

## পরিকল্পিত ফিচার (বিস্তারিত: `NEXT_LEVEL_PLAN.md`)
আসল fuel ও boost pickup, Level mode ও Endless mode (local ranking), বাংলাদেশি যানবাহন (CNG, রিকশা, বাস, ইজি বাইক), বাংলাদেশি map (সাজেক, বান্দরবান, সিলেট, খাগড়াছড়ি, কাপ্তাই), checkpoint, customization, মোবাইল control।
